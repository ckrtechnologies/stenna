# Stenna Sales Boy Mobile App (`app_salesboy`)

This folder contains the React Native (Bare CLI, New Architecture, JavaScript) companion app for Stenna Wallpaper field sales representatives.

The complete architectural plan and screen-by-screen specification is available at:
👉 [docs/APP_SALESBOY_SPEC.md](file:///Users/chandanmallik/projects/stenna/docs/APP_SALESBOY_SPEC.md)

### Quick Summary of Screens:
- **S-01**: Splash & Auto-Session Check (`SplashScreen.jsx`)
- **S-02**: Sales Rep Phone + Password Login (`LoginScreen.jsx`)
- **S-03**: Field Sales Dashboard & Daily Targets (`DashboardScreen.jsx`)
- **S-04**: Assigned Retail Shops Directory with Search & Zone Filters (`ShopsDirectoryScreen.jsx`)
- **S-05**: Shop 360° Profile & Audit History (`ShopDetailScreen.jsx`)
- **S-06**: Rapid 30-Sec Field Visit Logging Form (`RecordVisitScreen.jsx`)
- **S-07**: Catalog Book Pitch & Order Multi-Selector Modal (`BookPickerModal.jsx`)
- **S-08**: Visit Success & Sync Receipt (`VisitSuccessScreen.jsx`)
- **S-09**: Field Visits Personal Ledger (`VisitsLedgerScreen.jsx`)
- **S-10**: Rep Profile, Territory Badges & Offline Sync Center (`ProfileScreen.jsx`)
